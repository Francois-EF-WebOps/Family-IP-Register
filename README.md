# Family IP Register

An open, evidence-led register for documenting intellectual property, authorship, provenance, licensing, disclosure history, stewardship, and responsible commercialisation across family projects.

This repository is a **record-keeping and governance index**. It is not a declaration that every listed asset is owned exclusively by one person or by the family, and it is not legal advice.

## Operating principles

1. **Family purpose:** preserve the family's ability to create, use, maintain, share, and benefit from its work over time.
2. **Open by default, deliberately:** publish research and reusable tools where appropriate; do not assume every asset, dataset, source, or contribution can be relicensed or disclosed.
3. **Evidence before claims:** distinguish verified facts, repository metadata, contributor statements, and unresolved issues.
4. **No retroactive assumptions:** a repository owner's account is not, by itself, proof of sole authorship, inventorship, or ownership.
5. **Disclosure matters:** record the earliest known public disclosure and the licence in force at that time. Making a repository private later does not erase earlier disclosure.
6. **Protect people:** never put personal family records, identity documents, credentials, private correspondence, children's information, or confidential source material in this public repository.
7. **Commercial reality:** record actual users, buyers, employers, partners, or other external demand. An idea or expression of interest is not a sale.
8. **No premature filings:** do not publish enabling technical detail for a potentially patentable invention until disclosure and filing implications have been reviewed in relevant jurisdictions.

- [Asset manifest template](ASSET_MANIFEST_TEMPLATE.md) — record provenance, rights, restrictions, and reuse.
- [Media and Character Asset Discovery](docs/MEDIA_ASSET_DISCOVERY.md) — cross-repository discovery of existing personas, presenter characters, voice references, and media assets; explicitly distinguishes verified leads from unlocated files.

## Status vocabulary

- **Unreviewed** — identified, not yet examined.
- **Provisional** — recorded from available repository metadata or project notes; not independently verified.
- **Verified** — supported by primary evidence recorded in the register.
- **Disputed** — material disagreement or conflicting evidence exists.
- **Archived** — retained for history; no longer actively maintained.

## Important

This repository is public. Only publish information that is safe and appropriate for public release. Keep sensitive evidence in private storage and record only a non-sensitive description or reference here. Do not upload patent-sensitive implementation details before deciding whether to file.

## Scope

The register can cover software, research, datasets, documentation, designs, media, inventions, brands, domain names, and other creative or technical outputs. It should also record third-party dependencies, open-source components, collaborators, employment or client obligations, and any rights that may limit reuse.
