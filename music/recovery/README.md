# Recovery Workspace

This directory contains source reconciliation, duplicate decisions and recovery tracking. It is not a substitute for original source files.

- `ARCHIVE_MAP.md`: chronological map of known music work and recovery scope.
- `DUPLICATE_POLICY.md`: classification and preservation rules.
- `duplicate-register.jsonl`: current duplicate/repeated-evidence decisions.
- `RECOVERY_QUEUE.md`: remaining acquisition and verification work.

All source material is preserved. A duplicate decision never authorizes deletion.
